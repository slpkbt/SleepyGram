## SleepyGram 7.5.3

- **Выделение результатов поиска в чате или топике.** Нажмите правой кнопкой на результат и выберите **Select Loaded Forwardable Results**. Клиент выделит уже загруженные сообщения, которые можно переслать, учитывая текущие фильтры. Число видно в меню; лишнее можно снять кликом перед открытием обычного диалога пересылки. Чтобы захватить больше результатов, сначала прокрутите список. Лимит 10 000, без автоматической пересылки.
- **Поиск не переносит выделение между фильтрами.** При смене условий поиска старое выделение сбрасывается. В меню пересылки выбранных результатов видно число сообщений.
- **macOS: проверка обновления до перезапуска.** SleepyGram проверяет подготовленную сборку средствами macOS. Если система её отклоняет, установленный клиент остаётся открытым; в настройках обновления можно перейти к GitHub Releases. Для перехода с 7.5.2, если встроенное обновление не срабатывает, скачайте новый DMG вручную. Проверка не отключает Gatekeeper и не добавляет подпись Apple Developer ID или нотарификацию.
- Экспорт нового офлайн-архива доступен. Обновление существующего архива остаётся отключённым.

## English

- Right-click a result in a chat or topic search to select **loaded, forwardable results** up to the 10,000-message limit. Scroll to load more, remove anything you don't want and use the regular forwarding dialog. Nothing is sent automatically. Changing search filters clears the selection, and the forward action shows the selected count.
- On macOS, SleepyGram checks the prepared update before restarting and keeps the installed app running if macOS rejects it. The settings page links to GitHub Releases. If you cannot update from 7.5.2 in-app, download the new DMG manually. This does not disable Gatekeeper or add Apple notarization.
- Fresh offline exports remain available. Updating an existing archive is still disabled.
